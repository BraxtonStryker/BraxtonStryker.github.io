# BraxtonStryker.github.io

The homepage for my study apps, served at https://braxtonstryker.github.io/.

- [Quiz Qrusher](https://braxtonstryker.github.io/Quiz_Qrusher/): multiple-choice practice quizzes from a question CSV ([repo](https://github.com/BraxtonStryker/Quiz_Qrusher))
- [Class Base](https://braxtonstryker.github.io/Class_Base/): search your lecture slides and textbooks ([repo](https://github.com/BraxtonStryker/Class_Base))

One static `index.html`, with no build step and nothing loaded from other sites. Each app is its own repo, published by GitHub Pages under its own path.
