# BraxtonStryker.github.io

The homepage for my study apps, served at https://braxtonstryker.github.io/.

- [QuizQrusher](https://braxtonstryker.github.io/Quiz_Qrusher/): multiple-choice practice quizzes from a question CSV ([repo](https://github.com/BraxtonStryker/Quiz_Qrusher))
- [InfoBase](https://braxtonstryker.github.io/Class_Base/) (formerly Class Base): search your lecture slides and textbooks ([repo](https://github.com/BraxtonStryker/Class_Base))
- [CwikCard](https://braxtonstryker.github.io/CwikCard/): flashcards with spaced repetition, from the same question CSV ([repo](https://github.com/BraxtonStryker/CwikCard))
- [RunDown](https://braxtonstryker.github.io/RunDown/): a Markdown word processor with live preview ([repo](https://github.com/BraxtonStryker/RunDown))

One static `index.html`, with no build step and nothing loaded from other sites. Each app is its own repo, published by GitHub Pages under its own path. The repo and path names (`Quiz_Qrusher`, `Class_Base`) predate the apps' current names and stay as they are, so installed apps and saved data keep working.
